# 小步发布如何降低一人公司的决策成本

一个人做产品时，最大的浪费不是写错代码，而是长时间在错误方向上投入。

## 为什么节奏比完美更重要

- 你最稀缺的不是创意，而是验证速度。
- 每个版本都应该回答一个明确问题。
- 如果无法在一周内上线一个变化，范围通常已经过大。

> 小步发布的本质，是让市场更早参与产品判断。

## 一个简单框架

- 先定义本周最关键假设。
- 只实现验证这个假设所需的最小范围。
- 用内容、访谈或页面数据观察用户反应。

```ts
const rule = "build less, learn faster";
```

## 结论

持续的小循环，会比偶尔的大发布更适合一人公司。
