# 做 Agent 自动化前，先写一页 Brief

在接触工具之前，先回答四个问题：

- 输入来自哪里？
- 输出要给谁用？
- 哪些步骤不能自动化？
- 成功标准是什么？

## 最容易犯的错

把不清晰的流程直接塞给 AI。

## 结果

先写 Brief，会显著提升后续自动化的命中率。
